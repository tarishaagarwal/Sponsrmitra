# Static landing page (noticeboard design)

`index.html` is a single-file landing page in the same noticeboard look as the app: a hero, the problem, how it works, who it is for, and a waitlist section.

Before using it for real, replace both `https://forms.gle/REPLACE_WITH_YOUR_FORM_LINK` links with a real form address (for example a Google Form whose responses go to a Google Sheet). It also contains an illustrative statistic strip ("9 in 10 outreach emails go unanswered") that is not measured data. Change or remove it before publishing.
